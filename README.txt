NEOSPACE - WEBSITE GIAO DIỆN BÀI TẬP

NeoSpace là một website giới thiệu sản phẩm công nghệ được thiết kế
theo phong cách không gian hiện đại.

Website được xây dựng bằng HTML, CSS và JavaScript cơ bản, phù hợp
cho người mới học lập trình web hoặc dùng làm bài tập thực hành.

Giao diện có các phần:

- Thanh menu điều hướng.
- Phần giới thiệu đầu trang.
- Mô hình hành tinh với hiệu ứng 3D.
- Các card giới thiệu tính năng.
- Phần giới thiệu dự án.
- Phần liên hệ.
- Giao diện responsive trên điện thoại.

Website không sử dụng framework hoặc thư viện JavaScript phức tạp.

CÁCH MỞ WEBSITE

1. Giải nén thư mục website.
2. Mở thư mục bằng Visual Studio Code.
3. Mở file index.html.
4. Chọn Open with Live Server hoặc mở trực tiếp bằng trình duyệt.

CẤU TRÚC FILE

index.html
- Chứa nội dung và cấu trúc website.

style.css
- Chứa màu sắc, bố cục, responsive và hiệu ứng.

script.js
- Chứa logic mở menu và hiệu ứng nghiêng 3D.

Có thể thay đổi chữ, tiêu đề và nội dung trực tiếp trong file index.html.
